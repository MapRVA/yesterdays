# Georeferencing

If you are new to Yesterdays, we recommend starting with our [interactive tutorial](/getting-started/).

The _georeference interface_ is standard across Yesterdays.
For any image, collection, source, or subject there is a "**Georeference**" button which will take you to the same interface, with an image relevant to your selection.

!!! info "Already-georeferenced Images"
    If an image has already been georeferenced, you must be logged in to submit a new georeference.
    On the image detail page, scroll down to the "**Actions**" box and click on the "**Submit a Correction**" button.

## MapSwap

Clicking on the "**MapSwap**" button under the map takes you to [MapSwap](https://mapswap.trailsta.sh/), which makes it easy to switch to a different map provider's view of the same place.

## Advanced Options

### Context Images

When you're georeferencing an image, there's an option on the map to click **Advanced** which then allows you to turn *Context Images* on (*Clickable with popups*). This allows you to click any dot in the map and see the view and date of all the images that have already been placed. This contemporaneous context can sometimes be invaluable in locating the specific street corner or building you're looking at.

### Centerline

The _centerline_ option enables a dashed line in the map interface which extends outward from your georeferenced point.
In the image viewer, the same dashed line is rendered down the center of the image.
This feature makes it easier to align an image on the map by following the centerline's path.

### Coordinate and Direction Inputs

These text input fields allow you to manually enter a latitude, longitude, or direction for this image.
Please be careful when inputting data from external sources: metadata submitted by Yesterdays contributors must be public domain.

## Notes

If you want to reference another image in your *Additional Notes*, you can do so by simply preceding the other image's ID with a # symbol. For example, `#36066` would render as a link to [the image with that ID](https://yesterdays.today/36066/).

## Other

The [Resources page](https://maprva.org/resources/) on the MapRVA website has a host of other sources of information that can help you find your specific location.
